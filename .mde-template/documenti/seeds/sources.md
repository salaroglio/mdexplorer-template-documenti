# The sources

## TL;DR

Here the group puts the documents the wiki learns from: minutes, specifications, exported emails, notes. A source is
never modified: if something changes, a new source arrives.

- One file per source, with a name that says what it is and when: `minutes-2027-03-12.md`, `portal-specification-v2.md`.
- A PDF or an image is fine too, but the editor reads text better: when you can, add the `.md` version as well.
- A new source enters the wiki with the workflow «A source into the wiki».
